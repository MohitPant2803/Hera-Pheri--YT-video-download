## 🌐 Overview

**HERA PHERI** is a cinematic meme-driven media downloader frontend inspired by the legendary chaos of the Hera Pheri universe.

Instead of building a boring corporate downloader, this project transforms the experience into a full Bollywood-style “media arrangement operation” — complete with CRT terminals, dramatic loading states, shady office aesthetics, fake recovery departments, and iconic dialogue-driven interactions.

This project combines:

* modern frontend engineering
* cinematic UI storytelling
* expressive microcopy
* Bollywood meme culture
* chaotic world-building
* immersive interaction design

#  Installation

Clone the repository:

```bash
git clone <your-repo-url>
```

Navigate into project:

```bash
cd hera-pheri-downloader
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```
